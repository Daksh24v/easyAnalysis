Mengenterminologie

Das Wichtigste in drei Sätzen
  • Eine Menge ist ein „Sack“ voller Elemente; Reihenfolge und Wiederholungen spielen keine Rolle.
  • Eine Funktion ordnet jedem Element links genau ein Element rechts zu. Injektiv heißt „keine zwei Pfeile treffen dasselbe Ziel“, surjektiv heißt „jedes Ziel wird getroffen“.
  • Zwei Mengen sind „gleich groß“, wenn man sie per Bijektion perfekt paaren kann. So sieht man: ℕ, ℤ und ℚ sind gleich groß, ℝ ist echt größer.

Definition 1.1 · Teilmenge

B ⊆ A falls x ∈ A für alle x ∈ B.

Auf Deutsch: Alles, was in B steckt, steckt auch in A. B ist ein „Ausschnitt“ von A.

Am schnellsten zeigst du beides auf einmal mit einer Äquivalenzkette: Du startest mit x ∈ linke Seite, übersetzt mit der Tabelle oben in Logik, formst die Logik um und übersetzt zurück, bis x ∈ rechte Seite dasteht. Jeder Schritt muss ein echtes „⇔“ sein. Bist du bei einem Schritt unsicher, zeig die beiden Richtungen ⊆ und ⊇ getrennt.
Merkhilfe für De Morgan: Beim Verneinen wird aus „und“ ein „oder“ und umgekehrt. „Nicht (Regen und kalt)“ heißt „nicht Regen oder nicht kalt“.

Beispiel: Aufgabe 2.2 aus der Übung

Beweise die folgenden Rechenregeln, indem du sie auf x ∈ A bzw. x ∉ A und so weiter zurückführst.

a) A ∪ (B ∪ C) = (A ∪ B) ∪ C

Sei x beliebig. Dann gilt:

x ∈ A ∪ (B ∪ C)
⇔ x ∈ A oder x ∈ B ∪ C
⇔ x ∈ A oder (x ∈ B oder x ∈ C)
⇔ (x ∈ A oder x ∈ B) oder x ∈ C
⇔ x ∈ A ∪ B oder x ∈ C
⇔ x ∈ (A ∪ B) ∪ C

Warum gilt der mittlere Schritt? Beide Aussagen sagen dasselbe: „x liegt in mindestens einer der drei Mengen.“ Wo die Klammer steht, ändert daran nichts. Formal ist das die Assoziativität von „oder“.
Ergebnis: Da die Kette für jedes x gilt, haben beide Seiten genau dieselben Elemente, also sind sie gleich. ∎

b) A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

Hier hilft eine Fallunterscheidung nach x ∈ A oder x ∉ A, genau wie die Aufgabe es vorschlägt.

Fall 1: x ∈ A. Dann liegt x in A ∪ (B ∩ C), denn A ist ein Teil davon. Ebenso liegt x in A ∪ B und in A ∪ C, also auch im Schnitt der beiden. Links und rechts: x ist drin.

Fall 2: x ∉ A. Dann trägt A nichts bei, und es bleibt:

x ∈ A ∪ (B ∩ C) ⇔ x ∈ B ∩ C ⇔ x ∈ B und x ∈ C
x ∈ (A ∪ B) ∩ (A ∪ C) ⇔ x ∈ A ∪ B und x ∈ A ∪ C ⇔ x ∈ B und x ∈ C

Beide Seiten sind also wieder dieselbe Aussage.
Ergebnis: In jedem Fall liegt x genau dann links, wenn es rechts liegt. Also sind die Mengen gleich. ∎
Kurz als Äquivalenzkette:

x ∈ A ∨ (x ∈ B ∧ x ∈ C)
⇔ (x ∈ A ∨ x ∈ B) ∧ (x ∈ A ∨ x ∈ C)

Das ist das Distributivgesetz der Logik, „oder“ verteilt sich über „und“.

c) A \ (B ∩ C) = (A \ B) ∪ (A \ C)

Sei x beliebig. Dann gilt:

x ∈ A \ (B ∩ C)
⇔ x ∈ A und x ∉ B ∩ C
⇔ x ∈ A und nicht (x ∈ B und x ∈ C)
⇔ x ∈ A und (x ∉ B oder x ∉ C)   (De Morgan)
⇔ (x ∈ A und x ∉ B) oder (x ∈ A und x ∉ C)   (Distributiv)
⇔ x ∈ A \ B oder x ∈ A \ C
⇔ x ∈ (A \ B) ∪ (A \ C)

Der entscheidende Schritt ist De Morgan: „x liegt nicht in beiden Mengen B und C“ heißt „x fehlt in mindestens einer davon“. Danach verteilt man „x ∈ A und …“ auf beide Teile.
Ergebnis: Beide Seiten haben dieselben Elemente. ∎
Probe mit Zahlen: A = {1, 2, 3}, B = {3, 4}, C = {2, 3, 5}. Links: A \ {3} = {1, 2}. Rechts: {1, 2} ∪ {1} = {1, 2} ✓

Typische Fallen
  • Ein Beispiel ist kein Beweis. Die Probe mit Zahlen zeigt nur, dass die Regel für diese drei Mengen stimmt. Der Beweis muss für ein beliebiges x und beliebige Mengen funktionieren.
  • Beim Verneinen kippt „und“ zu „oder“. x ∉ B ∩ C heißt nicht „x ∉ B und x ∉ C“, sondern „x ∉ B oder x ∉ C“.
  • Differenz ist nicht kommutativ. A \ B = {1, 2}, aber B \ A = {4}.

1.3Abbildungen: injektiv, surjektiv, bijektiv

Eine Abbildung f : A → B ist eine Maschine: Du gibst ein Element aus A hinein und bekommst genau ein Element aus B heraus. A heißt Definitionsbereich, B Zielbereich.

Definition 1.2 · korrigiert

Eine Funktion f : A → B heißt
injektiv, falls ∀x, y ∈ A : x ≠ y ⇒ f(x) ≠ f(y),
surjektiv, falls ∀y ∈ B ∃x ∈ A : f(x) = y,
bijektiv, falls f injektiv und surjektiv ist.

Auf Deutsch: Injektiv bedeutet, dass verschiedene Eingaben verschiedene Ausgaben liefern; man kann also von der Ausgabe eindeutig auf die Eingabe zurückschließen. Surjektiv bedeutet, dass jedes Element im Ziel tatsächlich „erreicht“ wird. Bijektiv heißt beides, dann gibt es eine Umkehrfunktion f−1.

Achtung, häufiger Schreibfehler

Manchmal liest man bei injektiv „∀x≠y : f(x) = f(y)“. Das ist falsch, richtig ist f(x) ≠ f(y). Gleichwertig und beim Beweisen oft praktischer: aus f(x) = f(y) folgt x = y.

Beispiel: dieselbe Formel, verschiedene Antworten

Nimm f(x) = x². Ob das injektiv oder surjektiv ist, hängt davon ab, welche Mengen du links und rechts nimmst:

  • f : ℝ → ℝ: nicht injektiv, weil f(−2) = f(2) = 4. Nicht surjektiv, weil −1 nie herauskommt.
  • f : [0, ∞) → ℝ: injektiv (keine negativen Eingaben mehr), aber immer noch nicht surjektiv.
  • f : [0, ∞) → [0, ∞): bijektiv. Die Umkehrfunktion ist √y.
Beispiel

g : ℕ → ℕ, n ↦ 2n ist injektiv (aus 2n = 2m folgt n = m), aber nicht surjektiv, denn ungerade Zahlen wie 3 werden nie getroffen.

1.4Kardinalität: Wann sind zwei Mengen gleich groß?

Bei endlichen Mengen zählt man einfach. Bei unendlichen Mengen geht das nicht, also nimmt man die Idee vom Paare-Bilden: Wenn du jedem Element von A genau einen Partner in B geben kannst und niemand übrig bleibt, sind A und B gleich groß.

Kardinalitäten

|A| = |B|, falls es eine Bijektion A → B gibt.
|A| ≥ |B|, falls es eine Surjektion A → B gibt.

Auf Deutsch: Wenn du mit den Elementen von A alle Elemente von B „abdecken“ kannst, hat A mindestens so viele Elemente wie B.

Axiom 1.3 · Auswahlaxiom (in der Form der Vorlesung)

Eine Surjektion A → B existiert genau dann, wenn eine Injektion B → A existiert.

Auf Deutsch: „A deckt B ab“ ist dasselbe wie „B passt in A hinein“. Von der Surjektion zur Injektion muss man für jedes y ∈ B ein Urbild auswählen, bei unendlich vielen y gleichzeitig. Genau dieses Auswählen erlaubt das Axiom.

Satz 1.4 und Satz 1.5 · Cantor-Bernstein

Für alle A, B gilt |A| ≤ |B| oder |A| ≥ |B|.
Gibt es Injektionen A → B und B → A, dann gibt es auch eine Bijektion.

Auf Deutsch: Größen lassen sich immer vergleichen. Und wenn jede Menge in die andere hineinpasst, sind sie gleich groß. Das klingt selbstverständlich, ist bei unendlichen Mengen aber ein echter Satz und sehr nützlich: Statt einer (oft schwer zu findenden) Bijektion reichen zwei Injektionen.

1.5Abzählbar, und warum ℝ größer ist

Definition 1.6 · abzählbar

A heißt abzählbar, falls |A| = |ℕ|. Man schreibt |A| = ℵ0 (Aleph null).

Auf Deutsch: Man kann die Elemente als Liste „erstes, zweites, drittes, …“ aufschreiben, sodass jedes Element irgendwann drankommt.

Beispiel: ℤ ist abzählbar

Die naive Liste 0, 1, 2, 3, … erreicht die negativen Zahlen nie. Der Trick ist, hin und her zu springen:

0, 1, −1, 2, −2, 3, −3, …

Als Formel: f(n) = (n+1)/2 für ungerades n und f(n) = −n/2 für gerades n. Das ist eine Bijektion ℕ → ℤ.

Beispiel: ℚ ist abzählbar

Schreibe alle Brüche p/q in ein Gitter (Zeile q, Spalte p) und laufe es entlang der Diagonalen ab: 1/1, 2/1, 1/2, 3/1, 2/2, 1/3, …. Doppelte wie 2/2 = 1/1 überspringst du. Jede Diagonale ist endlich, also kommt jeder Bruch irgendwann dran. Negative Brüche baust du wie bei ℤ abwechselnd ein. Damit ist |ℚ| = ℵ0, obwohl ℚ „überall dicht“ liegt.

Cantors Diagonalargument: ℝ ist nicht abzählbar

Beweis durch Widerspruch. Angenommen, jemand gibt dir eine vollständige Liste aller Zahlen in [0, 1]. Du baust daraus eine Zahl x, die garantiert nicht in der Liste steht: Die k-te Nachkommastelle von x wählst du anders als die k-te Stelle der k-ten Zahl. Eine konkrete Regel: dk = 2 falls dkk = 1, sonst dk = 1.

x₁ = 0.14159…
x₂ = 0.21182…
x₃ = 0.33333…
x₄ = 0.50010…
x₅ = 0.77771…
x = 0.22122…

x unterscheidet sich von x1 an Stelle 1, von x2 an Stelle 2 und allgemein von xk an Stelle k. Also ist x ≠ xk für alle k, die Liste war doch nicht vollständig. Widerspruch, also |ℝ| > ℵ0.

Merke

Warum nur die Ziffern 1 und 2? Weil Zahlen wie 0.0999… = 0.1000… zwei Dezimaldarstellungen haben. Mit nur 1en und 2en kann x nie auf so einen Doppelgänger hereinfallen.

Achtung

Hier heißt „abzählbar“ genau gleich groß wie ℕ, also abzählbar unendlich. Manche Bücher zählen auch endliche Mengen als abzählbar. In der Klausur gilt die Definition aus der Vorlesung.

Endlich, abzählbar, überabzählbar: die drei Größenklassen

Jede Menge fällt in genau eine von drei Schubladen. Die Frage dahinter ist immer: Kann ich den Elementen Nummern geben, 1., 2., 3., …, sodass jedes Element irgendwann eine Nummer bekommt?

KlasseBedeutungBeispiele
endlichMan kann die Elemente zählen und ist irgendwann fertig.∅, {1, 2, 3}, {z ∈ ℤ : |z| ≤ 100}
abzählbarUnendlich, aber durchnummerierbar: Es gibt eine Bijektion ℕ → A.ℕ, ℤ, ℚ, gerade Zahlen, Primzahlen
überabzählbarUnendlich und nicht durchnummerierbar.ℝ, [0, 1], (2, 2.001), ℝ \ ℚ, 𝒫(ℕ)
Merke: so begründest du es in der Übung

Endlich: alle Elemente aufzählen oder zählen.
Abzählbar: eine Nummerierung angeben, am besten als Formel „das n-te Element ist …“, also eine Bijektion f : ℕ → A. Dann kurz sagen, warum jedes Element genau einmal drankommt.
Überabzählbar: eine bekannte überabzählbare Menge darin finden, meistens ein Intervall. Denn wäre A abzählbar, wäre jede unendliche Teilmenge davon auch abzählbar.

Typische Fallen
  • Unendlich heißt nicht überabzählbar. ℕ, ℤ und ℚ sind unendlich, aber abzählbar.
  • Die Nummerierung muss nicht der Größe nach gehen. Bei ℤ nummeriert man 0, 1, −1, 2, −2, … Es zählt nur, dass jedes Element irgendwann drankommt.
  • „Dicht“ heißt nicht überabzählbar. ℚ liegt überall dicht auf der Zahlengeraden und ist trotzdem abzählbar.
  • Die Länge eines Intervalls ist egal. Auch [0, 0.001] ist überabzählbar, es hat genauso viele Punkte wie ganz ℝ. Nur [a, a] = {a} ist endlich.
  • Erst die Menge ausschreiben. Prüfe, ob die Elemente aus ℕ, ℤ oder ℝ kommen. {z ∈ ℤ : |z| ≤ 5} ist endlich, {x ∈ ℝ : |x| ≤ 5} ist überabzählbar. Es ist dieselbe Bedingung, aber eine andere Grundmenge.

Beispiel: Aufgabe 2.4 aus der Übung

Sind die folgenden Mengen endlich, abzählbar oder überabzählbar?

a) A = {z ∈ ℤ : z < 10}

Ausschreiben: A = {9, 8, 7, …, 0, −1, −2, …}, alle ganzen Zahlen unter 10.
Unendlich: Es geht nach unten immer weiter, also nicht endlich.
Nummerierung: 1. Element 9, 2. Element 8, 3. Element 7, usw. Als Formel mit ℕ = {0, 1, 2, …}: f(n) = 9 − n. Jedes z < 10 bekommt genau eine Nummer, nämlich n = 9 − z. Für z = −5 ist das n = 14.
Ergebnis: abzählbar. Kurz begründet: A ist unendlich und eine Teilmenge der abzählbaren Menge ℤ.

b) B = {alle geraden natürlichen Zahlen}

Ausschreiben: B = {0, 2, 4, 6, …}.
Nummerierung: Die n-te gerade Zahl ist 2n, also f : ℕ → B, n ↦ 2n. Das ist injektiv (aus 2n = 2m folgt n = m) und surjektiv (jede gerade Zahl b ist f(b/2)), also bijektiv.
Ergebnis: abzählbar. Das ist das klassische überraschende Beispiel: Es gibt „genauso viele“ gerade Zahlen wie natürliche Zahlen, obwohl B nur jede zweite Zahl enthält.

c) C = {x ∈ ℝ : |x| ≤ c} für festes c > 1

Ausschreiben: |x| ≤ c heißt −c ≤ x ≤ c, also C = [−c, c], ein Intervall reeller Zahlen. Für c = 2 ist das [−2, 2].
Begründung: Wegen c > 1 liegt [0, 1] ganz in C. Nach Cantors Diagonalargument ist [0, 1] überabzählbar. Wäre C abzählbar, wäre auch die unendliche Teilmenge [0, 1] abzählbar. Das ist ein Widerspruch.
Alternativ direkt: g(t) = −c + 2ct ist eine Bijektion von [0, 1] nach [−c, c], also |C| = |[0, 1]|.
Ergebnis: überabzählbar. Die Bedingung c > 1 macht die Begründung bequem. Überabzählbar wäre C aber für jedes c > 0.

Selbst testen
Ist f : ℤ → ℤ, x ↦ x + 1 bijektiv?

Ja. Injektiv: aus x+1 = y+1 folgt x = y. Surjektiv: zu jedem y ist x = y − 1 ein Urbild. Die Umkehrfunktion ist y ↦ y − 1.

Wie viele Elemente hat 𝒫({a, b, c})? Schreib sie auf.

2³ = 8: ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}.

Beweise A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C).

x ∈ A ∩ (B ∪ C) ⇔ x ∈ A und (x ∈ B oder x ∈ C) ⇔ (x ∈ A und x ∈ B) oder (x ∈ A und x ∈ C) ⇔ x ∈ (A ∩ B) ∪ (A ∩ C). Der mittlere Schritt ist das Distributivgesetz der Logik: „und“ verteilt sich über „oder“.

Ist ℕ × ℕ abzählbar?

Ja, mit demselben Diagonal-Durchlauf wie bei ℚ: (0,0), (1,0), (0,1), (2,0), (1,1), (0,2), … Jede Diagonale ist endlich, also kommt jedes Paar dran.

Reelle Zahlen und Vektoren

Das Wichtigste in drei Sätzen
  • ℝ ist ein angeordneter Körper: Man kann rechnen wie gewohnt und Zahlen der Größe nach vergleichen.
  • Was ℝ von ℚ unterscheidet, ist die Vollständigkeit: Jede nach oben beschränkte Menge hat eine kleinste obere Schranke, das Supremum. Die Zahlengerade hat also keine „Löcher“.
  • Im ℝⁿ misst man Längen mit der Norm und Winkel mit dem Skalarprodukt. Cauchy-Schwarz und die Dreiecksungleichung sind die Werkzeuge, die du ständig brauchst.

(1) Für jedes x gilt genau eins: x > 0, x < 0 oder x = 0.
(2) x, y > 0 ⇒ x+y > 0 und x·y > 0.
(3) x > y ⇔ x − y > 0.

Auf Deutsch: Jede Zahl ist positiv, negativ oder null, und Summe und Produkt positiver Zahlen sind positiv. „Größer“ heißt einfach: die Differenz ist positiv. Daraus folgen alle bekannten Regeln für Ungleichungen.

Merke: Warum ℂ nicht angeordnet werden kann

In jedem angeordneten Körper ist jedes Quadrat ≥ 0: Für x > 0 ist x·x > 0 nach (2), und für x < 0 ist x² = (−x)² > 0. Insbesondere ist 1 = 1² > 0. In ℂ wäre aber i² = −1 < 0. Widerspruch.

Intervalle: was eckige und runde Klammern bedeuten

Ein Intervall ist ein zusammenhängendes Stück der Zahlengeraden, zum Beispiel „alle Zahlen zwischen 2 und 5“. Offen bleibt dabei nur eine Frage: Gehören die Randpunkte 2 und 5 selbst dazu oder nicht? Genau das sagen die Klammern, und zwar für jede Seite einzeln.

Die Regel

Eckige Klammer [ ]: der Randpunkt gehört dazu. Das entspricht ≤.
Runde Klammer ( ): der Randpunkt gehört nicht dazu. Das entspricht <.
Eselsbrücke: Die eckige Klammer „hält den Randpunkt fest“ wie ein Haken, die runde Klammer ist weich und lässt ihn los.

∞ ist keine reelle Zahl, sondern nur ein Zeichen für „es geht unbegrenzt weiter“. Ein Punkt, den es nicht gibt, kann auch nicht dazugehören. Deshalb schreibt man [0, ∞) und nie [0, ∞]. [0, ∞) heißt also einfach „alle Zahlen ≥ 0“.

2.2Schranken, Maximum, Supremum

Das ist der wichtigste Begriff dieses Kapitels und der Grund, warum man in der Analysis mit ℝ statt mit ℚ arbeitet.

Definitionen 2.2–2.4

Obere Schranke von M: jedes x mit y ≤ x für alle y ∈ M.
Maximum: eine obere Schranke, die selbst in M liegt.
Supremum sup(M): die kleinste obere Schranke.

Auf Deutsch: Eine obere Schranke ist eine „Decke“, an die kein Element von M stößt. Das Supremum ist die tiefste Decke, die noch passt. Das Maximum ist das größte Element, falls es eins gibt. Wenn es ein Maximum gibt, ist es auch das Supremum.

Immer zwei Schritte. (a) s ist eine obere Schranke: y ≤ s für alle y ∈ M. (b) Nichts Kleineres funktioniert: Zu jedem ε > 0 gibt es ein y ∈ M mit y > s − ε.

Definition 2.5 und Axiom 2.6 · Vollständigkeit

ℝ ist vollständig: Hat eine Teilmenge von ℝ mindestens ein Element und eine obere Schranke, dann hat sie auch ein Supremum in ℝ. Ein angeordneter Körper mit dieser Eigenschaft heißt vollständig.

Auf Deutsch: In ℝ gibt es keine Löcher. Wo eine Menge „hinstrebt“, da gibt es auch eine Zahl.

Beispiel: ℚ ist nicht vollständig (Übung)

Nimm M = {x ∈ ℚ : x² < 2}. M ist nach oben beschränkt (z. B. durch 2). In ℝ wäre das Supremum √2, aber √2 ist irrational. Innerhalb von ℚ gibt es keine kleinste obere Schranke: Zu jeder rationalen oberen Schranke findet man eine noch kleinere, die näher an √2 liegt. ℚ hat also an der Stelle √2 ein Loch.

Beispiel: ℚ ist dicht in ℝ (Übung)

Zwischen zwei reellen Zahlen x < y liegt immer ein Bruch. Explizit: Wähle n ∈ ℕ mit 1/n < y − x und setze z = (⌊nx⌋ + 1)/n. Dann ist x < z ≤ x + 1/n < y.
Zahlenbeispiel: x = 0.31, y = 0.35. Mit n = 50 gilt 1/50 = 0.02 < 0.04, ⌊15.5⌋ = 15, also z = 16/50 = 0.32.

Ganz analog gibt es untere Schranke, Minimum und Infimum inf(M), die größte untere Schranke.

Konventionen

Für leere oder unbeschränkte Mengen vereinbart man: sup(∅) = −∞, sup(M) = +∞ falls M nach oben unbeschränkt, inf(∅) = +∞, inf(M) = −∞ falls nach unten unbeschränkt.

Max, Min, Inf, Sup: der Unterschied

Die vier Begriffe kommen paarweise. Sup und Max schauen nach oben, Inf und Min schauen nach unten. Der entscheidende Unterschied: Max und Min müssen Elemente von M sein, Sup und Inf nicht.

Merke

Bild dazu: M ist ein Raum. Das Supremum ist die Decke, so tief wie möglich gehängt. Das Maximum ist das Element, das die Decke wirklich berührt. Manchmal kommen die Elemente der Decke beliebig nahe, ohne sie je zu berühren. Dann gibt es ein Supremum, aber kein Maximum.

Rezept: sup, inf, max, min bestimmen und begründen

1. Elemente ausrechnen. Setz n = 1, 2, 3, 4 ein und schau, wo die Werte hinwandern. Daraus kommt die Vermutung für sup und inf.
2. Schranke zeigen. Zeig y ≤ s für jedes y ∈ M, meistens mit einer einfachen Abschätzung wie 1/n ≤ 1 oder 1/n > 0.
3. Liegt s in M? Wenn ja, findest du ein n, das genau s ergibt. Dann ist s das Maximum, und nach Teil d) unten automatisch auch das Supremum. Fertig.
4. Wenn nein: niemand Kleineres ist Schranke. Nimm ein beliebiges c < s und finde ein Element von M, das größer als c ist. Dafür ist der Hinweis da: Zu jedem r ∈ ℝ gibt es ein n ∈ ℕ mit n > r. Damit machst du 1/n kleiner als jede vorgegebene positive Zahl. Zum Schluss sagen: s ∉ M, also kein Maximum.
Für inf und min geht alles genauso, nur mit ≥ statt ≤ und „kleiner als c“ statt „größer als c“.

Typische Fallen
  • „Kein Maximum“ heißt nicht „kein Supremum“. (0, 1) hat kein Maximum, aber sup = 1.
  • Ein Wert, dem die Elemente nur nahekommen, ist kein Element. 0.999… ist hier gleich 1 und gehört nicht zu (0, 1). Es gibt kein „größtes Element knapp unter 1“.
  • Der Grenzwert ist nicht automatisch das Supremum. Bei Teil b) unten nähern sich die Werte ±1, aber sup = 3/2 und inf = −2 werden ganz am Anfang erreicht.
  • Nur zeigen, dass s eine Schranke ist, reicht nicht. 5 ist auch eine obere Schranke von (0, 1). Fürs Supremum musst du zeigen, dass keine kleinere Zahl funktioniert.

Beispiel: Aufgabe 2.5 aus der Übung

Bestimme, falls vorhanden, sup, inf, max und min und begründe es. Weil 1/0 nicht definiert ist, läuft n (und m) hier ab 1.

a) M₁ = {1 − 1/n : n ∈ ℕ}

Ausrechnen: 0, 1/2, 2/3, 3/4, 4/5, … Die Werte wachsen und kommen 1 immer näher.
Minimum: Wegen 1/n ≤ 1 ist 1 − 1/n ≥ 0 für alle n, also ist 0 eine untere Schranke. Für n = 1 ist 1 − 1 = 0 ∈ M1. Also min = inf = 0.
Obere Schranke: 1/n > 0, also 1 − 1/n < 1 für alle n.
Keine kleinere Schranke: Sei c < 1. Nach dem Hinweis gibt es ein n mit n > 1/(1 − c). Dann ist 1/n < 1 − c, also 1 − 1/n > c. Das Element 1 − 1/n liegt über c, also ist c keine obere Schranke. Damit ist sup = 1.
Maximum: 1 − 1/n = 1 hieße 1/n = 0, das geht nicht. Also 1 ∉ M1, kein Maximum.
Zahlenbeispiel zu c = 0.99: Der Hinweis liefert ein n > 100, etwa n = 101, und 1 − 1/101 ≈ 0.9901 > 0.99 ✓

Wie kommt man auf n > 1/(1 − c)?

Man rechnet rückwärts vom Ziel. Das n fällt nicht vom Himmel, man sucht es so:
Ziel: ein Element über c, also 1 − 1/n > c.
1. Umstellen: 1/n auf die rechte Seite und c nach links bringen: 1 − c > 1/n.
2. Nach n auflösen: Mit n multiplizieren gibt n(1 − c) > 1. Wegen c < 1 ist 1 − c > 0, also darf man durch 1 − c teilen, ohne dass sich das Zeichen umdreht: n > 1/(1 − c).
3. Gibt es so ein n? Ja, genau dafür ist der Hinweis da: Zu jedem r ∈ ℝ gibt es ein n > r. Setz r = 1/(1 − c).
4. Aufschreiben: In der Lösung schreibt man die Schritte dann vorwärts, so wie oben: erst das n wählen, dann zeigen, dass es funktioniert.
Zahlenbeispiel: c = 0.99. Dann ist 1 − c = 0.01 und 1/(1 − c) = 100. Also braucht man n > 100, etwa n = 101: 1 − 1/101 ≈ 0.9901 > 0.99 ✓. Je näher c an 1 liegt, desto größer muss n sein, aber ein passendes n gibt es immer.
Bei c) unten geht es genauso: Ziel 2/n < c, umgestellt n > 2/c.

b) M₂ = {(−1)ⁿ (1 + 1/n) : n ∈ ℕ}

Ausrechnen: Das Vorzeichen springt. Für gerades n kommt 1 + 1/n heraus, für ungerades n kommt −(1 + 1/n) heraus.

Maximum: 1/n ≤ 1 und 1/m ≤ 1, also ist jedes Element ≤ 2. Für n = m = 1 kommt genau 2 heraus. Also max = sup = 2.
Untere Schranke: Beide Brüche sind positiv, also ist jedes Element > 0.
Keine größere Schranke: Sei c > 0. Nach dem Hinweis gibt es ein n mit n > 2/c. Nimm m = n. Dann ist 1/n + 1/n = 2/n < c. Es gibt also ein Element unter c, und c ist keine untere Schranke. Damit ist inf = 0.
Minimum: Eine Summe von zwei positiven Zahlen ist nie 0, also 0 ∉ M3, kein Minimum.

Sei a = max M. Für das Supremum müssen wir zwei Dinge zeigen.
(1) a ist eine obere Schranke. Das steckt schon in der Definition des Maximums: y ≤ a für alle y ∈ M.
(2) a ist die kleinste obere Schranke. Sei x irgendeine obere Schranke von M. Weil a ∈ M liegt, muss x auch über a liegen: a ≤ x. Also ist a kleiner oder gleich jeder oberen Schranke.
Aus (1) und (2) folgt sup M = a = max M. ∎
Die Umkehrung gilt nicht: Aus „M hat ein Supremum“ folgt nicht „M hat ein Maximum“. Gegenbeispiel aus a): sup M1 = 1, aber M1 hat kein Maximum, weil 1 ∉ M1. Genauso hat M3 ein Infimum 0, aber kein Minimum.

2.3Offene und abgeschlossene Mengen

Definitionen 2.8–2.10

Ein offenes Intervall (a, b) mit x ∈ (a, b) heißt Umgebung von x.
A ⊆ ℝ heißt offen, falls jedes x ∈ A eine Umgebung Ix ⊆ A hat.
A heißt abgeschlossen, falls ℝ \ A offen ist.

Auf Deutsch: Offen heißt, jeder Punkt hat ein bisschen „Luft“ um sich herum, die noch in der Menge liegt. Du kannst dich von jedem Punkt aus ein kleines Stück nach links und rechts bewegen, ohne die Menge zu verlassen. Abgeschlossen heißt, das Komplement ist offen, oder anschaulich: die Menge enthält ihre Randpunkte.

Schritt für Schritt: warum [2, 5] abgeschlossen, aber nicht offen ist

Wir nehmen ein konkretes Intervall, [2, 5]. Mit a = 2 und b = 5 ist das genau die Zeile „[a, b]“ aus der Tabelle weiter unten.

Schritt 1: Was müssen wir überhaupt zeigen? Die Definition sagt: A ist abgeschlossen, wenn das Komplement ℝ \ A offen ist. Wir prüfen also gar nicht [2, 5] selbst, sondern alles, was übrig bleibt, wenn man [2, 5] aus der Zahlengeraden herausnimmt.

Schritt 2: Das Komplement aufschreiben. Übrig bleiben alle Zahlen kleiner als 2 und alle Zahlen größer als 5:

ℝ \ [2, 5] = (−∞, 2) ∪ (5, ∞)

Bei 2 und 5 stehen jetzt runde Klammern, weil 2 und 5 zu [2, 5] gehören und deshalb nicht im Komplement sind. Das ∪ heißt „oder“: links ein Stück, rechts ein Stück.

Schritt 3: Ist das Komplement offen? Offen heißt: Um jeden Punkt passt ein kleines offenes Intervall, das komplett in der Menge bleibt. Nimm irgendein x aus (5, ∞), etwa x = 5.3. Der Abstand zu 5 ist 0.3. Nimm die Hälfte davon als Radius: (5.15, 5.45) liegt ganz in (5, ∞) ✓. Das klappt für jedes x > 5, auch für x = 5.0001, dann eben mit Radius 0.00005. Allgemein funktioniert der Radius (x − 5)/2. Links von 2 geht es genauso mit Radius (2 − x)/2.

Der entscheidende Punkt: Der „gefährliche“ Randpunkt 5 gehört gar nicht zum Komplement. Jeder Punkt im Komplement hat also einen echten Abstand zu 5, und in diesen Abstand passt immer ein kleines Intervall.

Schritt 4: Ergebnis. Das Komplement (−∞, 2) ∪ (5, ∞) ist offen. Nach Definition ist [2, 5] also abgeschlossen.

Und warum ist [2, 5] nicht offen? Dafür reicht ein einziger Punkt ohne „Luft“. Das ist der Randpunkt 2: Er gehört zu [2, 5], aber jedes Intervall um 2, egal wie klein, ragt nach links hinaus. Zum Beispiel enthält (1.99, 2.01) die Zahl 1.995, und die liegt nicht in [2, 5]. Also ist [2, 5] nicht offen. Mit 5 geht dasselbe Argument nach rechts.

Weder offen noch abgeschlossen: [0, 1)

Hier gehört ein Randpunkt dazu (die 0) und der andere nicht (die 1). Beides stört:

  • Nicht offen, weil 0 in der Menge liegt und keine Luft hat: Jedes Intervall um 0 enthält negative Zahlen, z. B. −0.001, und die sind nicht in [0, 1).
  • Nicht abgeschlossen, weil das Komplement (−∞, 0) ∪ [1, ∞) nicht offen ist. Die 1 liegt im Komplement (eckige Klammer!), hat dort aber keine Luft: Jedes Intervall um 1 enthält Zahlen wie 0.999, und die gehören zu [0, 1), also nicht zum Komplement.
Merkhilfe für Intervalle

Schau nur auf die Randpunkte.
Kein Randpunkt gehört dazu (nur runde Klammern) ⇒ offen.
Alle Randpunkte gehören dazu (nur eckige Klammern, bei ∞ zählt rund nicht) ⇒ abgeschlossen.
Gemischt ⇒ weder noch.
Das ist eine Faustregel für Intervalle. Bei komplizierteren Mengen wie ℚ musst du die Definition benutzen.

2.4Der Vektorraum ℝⁿ

ℝn besteht aus Listen (x1, …, xn) reeller Zahlen; für Informatiker sind das Arrays der Länge n. Addition und Skalierung laufen komponentenweise.

Skalarprodukt und euklidische Norm

⟨x, y⟩ = x · y = Σk=1n xkyk    ‖x‖ = √(x · x) = √(Σ xk²)

Auf Deutsch: Das Skalarprodukt multipliziert Eintrag für Eintrag und summiert. Die Norm ist die Länge des Pfeils, also Pythagoras in n Dimensionen. Geometrisch gilt x · y = ‖x‖ ‖y‖ cos θ, wobei θ der Winkel zwischen den Vektoren ist. Bei x · y = 0 stehen sie senkrecht.

Beispiel zum Mitrechnen

x = (1, 2, 2), y = (3, 0, 4).
x · y = 1·3 + 2·0 + 2·4 = 11
‖x‖ = √(1 + 4 + 4) = 3,   ‖y‖ = √(9 + 0 + 16) = 5
Check mit Cauchy-Schwarz: |11| ≤ 3 · 5 = 15 ✓. Der Winkel ist cos θ = 11/15, also etwa 43°.

Die vier Grundeigenschaften sagen: Das Skalarprodukt ist symmetrisch, man kann Faktoren herausziehen, es ist distributiv, und x · x ≥ 0 mit Gleichheit nur für den Nullvektor.

2.5Drei Ungleichungen, die du immer brauchst

Lemma 2.12 · Cauchy-Schwarz

|⟨x, y⟩| ≤ ‖x‖ · ‖y‖, mit Gleichheit genau dann, wenn einer ein Vielfaches des anderen ist.

Auf Deutsch: Weil |cos θ| ≤ 1, kann das Skalarprodukt nie größer sein als das Produkt der Längen. Gleichheit gibt es nur, wenn die Vektoren auf einer Linie liegen.

Lemma 2.13 · Dreiecksungleichung

‖x + y‖ ≤ ‖x‖ + ‖y‖. In ℝ: |x + y| ≤ |x| + |y|.

Auf Deutsch: Der direkte Weg ist nie länger als ein Umweg. Beweis in einer Zeile: ‖x+y‖² = ‖x‖² + 2⟨x,y⟩ + ‖y‖² ≤ ‖x‖² + 2‖x‖‖y‖ + ‖y‖² = (‖x‖ + ‖y‖)², wobei im mittleren Schritt Cauchy-Schwarz benutzt wird.

Beispiel und umgekehrte Dreiecksungleichung

|3 + (−5)| = 2 ≤ 3 + 5 = 8. Gleichheit gibt es nur bei gleichem Vorzeichen (xy ≥ 0).
Die umgekehrte Dreiecksungleichung |x − y| ≥ ||x| − |y||, folgt so: |x| = |(x − y) + y| ≤ |x − y| + |y|, also |x| − |y| ≤ |x − y|. Mit vertauschten Rollen bekommst du dasselbe für |y| − |x|.

Lemma 2.14 · geometrisches ≤ arithmetisches Mittel

Für x, y ≥ 0 gilt √(xy) ≤ (x + y)/2, Gleichheit genau für x = y.

Auf Deutsch: Ein Rechteck mit Seiten x und y hat höchstens die Fläche eines Quadrats mit gleichem Umfang. Der Beweis startet mit dem Trick 0 ≤ (x − y)²; daraus wird 4xy ≤ (x + y)², dann Wurzel ziehen.

Beispiel

x = 4, y = 9: √36 = 6 ≤ 6.5 = 13/2 ✓. Und x = y = 5: √25 = 5 = 10/2, Gleichheit.

2.6Komplexe Zahlen

Eine komplexe Zahl ist ein Punkt in der Ebene: z = x + iy ≅ (x, y) mit Realteil Re(z) = x und Imaginärteil Im(z) = y. Neu ist nur eine Regel: i² = −1. Alles andere ist ganz normales Ausmultiplizieren.

Beispiel zum Mitrechnen

z1 = 1 + 2i, z2 = 3 − i.
Summe: z1 + z2 = 4 + i (komponentenweise).
Produkt: (1 + 2i)(3 − i) = 3 − i + 6i − 2i² = 3 + 5i + 2 = 5 + 5i.
Mit der Multiplikationsformel: x1x2 − y1y2 = 3 − (−2) = 5 und x1y2 + x2y1 = −1 + 6 = 5 ✓.

Merke

z · z = (x + iy)(x − iy) = x² + y² = |z|². Damit teilt man durch komplexe Zahlen: mit dem Konjugierten erweitern, dann ist der Nenner reell. Beispiel: 1/(1 + i) = (1 − i)/((1+i)(1−i)) = (1 − i)/2.

Selbst testen
Bestimme sup, inf, max und min von M = {1/n : n ≥ 1}.

Die Elemente sind 1, 1/2, 1/3, … max = sup = 1 (für n = 1). Alle Elemente sind > 0, und zu jedem c > 0 gibt es ein n > 1/c, also 1/n < c. Damit ist inf = 0. Weil 1/n nie 0 ist, gibt es kein Minimum.

Bestimme sup, inf, max, min von M = {(−1)ⁿ/n : n ∈ ℕ₊}.

Die Elemente sind −1, 1/2, −1/3, 1/4, … Größtes Element ist 1/2, also max = sup = 1/2. Kleinstes Element ist −1, also min = inf = −1.

Ist (0, 1) ∪ (2, 3) offen?

Ja. Jeder Punkt liegt in einem der beiden offenen Intervalle und hat dort schon eine Umgebung. Allgemein ist jede Vereinigung offener Mengen offen.

Berechne (2 + i)² und |2 + i|.

(2+i)² = 4 + 4i + i² = 3 + 4i, und |2 + i| = √5. Probe: |3 + 4i| = 5 = (√5)².

3

Folgen

Das Wichtigste in drei Sätzen
  • Eine Folge konvergiert gegen x, wenn sie ab einem gewissen Index für immer in jedem noch so schmalen Streifen um x bleibt (die ε-N-Definition).
  • Statt jedes Mal ε und N zu suchen, benutzt man Werkzeuge: Rechenregeln, Einschließung, „monoton und beschränkt ⇒ konvergent“.
  • Jede beschränkte Folge hat eine konvergente Teilfolge (Bolzano-Weierstraß), und Konvergenz kann man prüfen, ohne den Grenzwert zu kennen (Cauchy).

3.1Was ist eine Folge?

Formal ist eine Folge eine Abbildung ℕ → M, praktisch eine unendliche Liste x0, x1, x2, …. Für Informatiker: ein unendliches Array, oder ein Generator, der auf Anfrage das n-te Glied liefert.

Beispiel: explizit oder rekursiv

Explizit: xn = 2n, man kann jedes Glied direkt ausrechnen.
Rekursiv: x0 = 1, xn+1 = 2xn, jedes Glied ergibt sich aus dem vorherigen. Beides beschreibt dieselbe Folge 1, 2, 4, 8, …

Monoton wachsend heißt xn ≤ xn+1 für alle n; streng monoton wachsend heißt xn < xn+1. Fallend analog. Eine konstante Folge ist monoton wachsend und monoton fallend, aber nicht streng.

3.2Der Grenzwert

Definition 3.3 · Grenzwert

xn → x, falls es zu jedem ε > 0 ein N gibt, sodass |xn − x| < ε für alle n ≥ N.

Auf Deutsch: Stell dir ein Spiel vor. Dein Gegner wählt einen Streifen der Breite ε um x, so schmal er will. Du musst darauf ein N nennen, ab dem alle Folgenglieder im Streifen liegen. Wenn du dieses Spiel für jedes ε gewinnst, konvergiert die Folge gegen x. Je kleiner ε, desto größer muss N in der Regel werden.

Beispiel, sauber aufgeschrieben: 1/n → 0

Sei ε > 0 gegeben. Wähle N > 1/ε. Dann gilt für alle n ≥ N:

|xn − 0| = 1/n ≤ 1/N < ε.

Das ist schon der ganze Beweis. Das Muster ist immer gleich: Den Abstand |xn − x| ausrechnen oder nach oben abschätzen, dann N so wählen, dass die Abschätzung kleiner als ε wird.

Beispiel: (−1)ⁿ hat keinen Grenzwert

Die Folge springt −1, 1, −1, 1, … Wähle ε = 1. Für jeden Kandidaten x ist der Abstand zu 1 oder der zu −1 mindestens 1, denn die beiden Punkte liegen 2 auseinander. Also liegen unendlich viele Glieder außerhalb des Streifens, das Spiel ist für ε = 1 verloren.

Satz 3.4 · Eindeutigkeit

Jede reelle Folge hat höchstens einen Grenzwert.

Auf Deutsch: Wäre xn → x und xn → y, dann wäre |x − y| ≤ |x − xn| + |xn − y| < 2ε für jedes ε. Ein fester Abstand, der kleiner als jede positive Zahl ist, muss 0 sein.

3.3Werkzeuge für Grenzwerte

Lemma 3.5 · Ungleichungen bleiben erhalten

Aus xn ≤ yn für alle n, xn → x und yn → y folgt x ≤ y.

Falle

Aus < wird im Grenzwert nur ≤. Ein Beispiel: 1/n² < 1/n für n ≥ 2, aber beide Grenzwerte sind 0.

Satz 3.6 · Einschließung („Sandwich“)

Ist xn ≤ wn ≤ yn und xn → x, yn → x, dann auch wn → x.

Auf Deutsch: Wenn eine Folge zwischen zwei Folgen eingeklemmt ist, die zum selben Ziel laufen, hat sie keine Wahl und muss mit.

Beispiel

wn = sin(n)/n. Den Sinus kennen wir kaum, aber er liegt zwischen −1 und 1. Also gilt −1/n ≤ wn ≤ 1/n, beide Seiten gehen gegen 0, also wn → 0. Ein komplizierteres Beispiel funktioniert genauso: Ein riesiger Nenner wie 137n17 macht den Bruch kleiner als 1/n.

Definition 3.7 und Satz 3.8 · Divergenz und Beschränktheit

xn → +∞, falls es zu jedem C > 0 ein N gibt mit xn ≥ C für alle n ≥ N.
Beschränkt heißt: es gibt K mit |xn| ≤ K für alle n. Jede konvergente Folge ist beschränkt.

Auf Deutsch: „Gegen unendlich“ heißt, die Folge übersteigt jede Schranke und bleibt darüber. Und konvergente Folgen können nicht ausbrechen: Ab N sind alle Glieder nah am Grenzwert, und davor gibt es nur endlich viele.

Falle

Umgekehrt gilt es nicht: (−1)n ist beschränkt, konvergiert aber nicht. Und „unbeschränkt“ heißt nicht automatisch „geht gegen ∞“: 0, 1, 0, 2, 0, 3, … ist unbeschränkt, geht aber nicht gegen ∞, weil immer wieder 0 kommt.

Satz 3.9 · Rechenregeln

Aus xn → a und yn → b folgt xn ± yn → a ± b, xnyn → ab und, falls b ≠ 0, xn/yn → a/b.

Auf Deutsch: Grenzwerte vertragen sich mit den Grundrechenarten. Du darfst eine komplizierte Folge in einfache Bausteine zerlegen, deren Grenzwerte du kennst.

Beispiel: der Standard-Trick bei Brüchen

Bei Polynomen im Zähler und Nenner teilst du durch die höchste Potenz des Nenners:

(3n² + n) / (n² + 5) = (3 + 1/n) / (1 + 5/n²) → (3 + 0)/(1 + 0) = 3

Erst nach dem Kürzen sind die Rechenregeln anwendbar, denn vorher gehen Zähler und Nenner beide gegen ∞, und „∞/∞“ ist kein Grenzwert.

3.4Monotone Folgen

Satz 3.10 · monoton + beschränkt ⇒ konvergent

Jede monoton wachsende, beschränkte Folge konvergiert, und zwar gegen supn xn. Monoton fallend und beschränkt konvergiert gegen das Infimum.

Auf Deutsch: Wer immer nur nach oben geht, aber eine Decke hat, muss irgendwo zur Ruhe kommen, nämlich genau unter der tiefsten Decke, dem Supremum. Hier wird die Vollständigkeit von ℝ benutzt: In ℚ würde der Satz nicht gelten.

Beispiel: x₍ₙ₊₁₎ = √xₙ
n123456…
x₁ = 0.20.2000.4470.6690.8180.9040.951→ 1
x₁ = 1616421.4141.1891.091→ 1

Startest du unter 1, wächst die Folge monoton und ist durch 1 beschränkt. Startest du über 1, fällt sie monoton und ist durch 1 nach unten beschränkt. In beiden Fällen konvergiert sie nach Satz 3.10. Den Grenzwert x findest du, indem du in der Rekursion xn und xn+1 durch x ersetzt: x = √x, also x = 0 oder x = 1. Da die Folge bei x₁ = 0.2 wächst, kann es nicht 0 sein, also 1.

Merke

Der Trick „Grenzwert in die Rekursion einsetzen“ funktioniert nur, wenn du vorher weißt, dass die Folge konvergiert. Bei xn+1 = 2xn liefert er x = 2x, also x = 0, obwohl 1, 2, 4, 8, … gegen ∞ geht.

3.5limsup, liminf und Häufungspunkte

Nicht jede beschränkte Folge konvergiert. Aber man kann trotzdem fragen: Wo hält sich die Folge auf Dauer auf? Dafür gibt es drei Begriffe.

Definition 3.11 · Teilfolge und Häufungspunkt

Für Indizes n1 < n2 < n3 < … heißt (xnk)k Teilfolge. x heißt Häufungspunkt von (xn), falls es eine Teilfolge gibt, die gegen x konvergiert.

Auf Deutsch: Eine Teilfolge entsteht, wenn du unendlich viele Glieder auswählst und die Reihenfolge beibehältst. Ein Häufungspunkt ist ein Ort, an den die Folge immer wieder zurückkommt, unendlich oft beliebig nah.

limsup und liminf

xn = supk≥n xk ist monoton fallend, xn = infk≥n xk ist monoton wachsend.
limsup xn = lim xn,   liminf xn = lim xn.

Auf Deutsch: Schau dir ab Index n den ganzen „Schwanz“ der Folge an und nimm das Supremum. Wenn du n vergrößerst, fallen frühe Ausreißer weg, die obere Kurve sinkt. Wohin sie sinkt, ist der limsup. Grob gesagt: der größte Wert, den die Folge auf Dauer immer wieder erreicht.

Satz 3.12 · Bolzano-Weierstraß

Für eine beschränkte Folge sind limsup und liminf der größte bzw. kleinste Häufungspunkt. Außerdem gilt: xn → x ⇔ liminf xn = limsup xn = x.

Auf Deutsch: Alle Häufungspunkte liegen zwischen liminf und limsup, und die beiden Ränder sind selbst Häufungspunkte. Die Folge konvergiert genau dann, wenn oben und unten zusammenfallen, also wenn es nur einen Häufungspunkt gibt.

Folgerung: das ist der Satz, den man meistens zitiert

Jede beschränkte reelle Folge hat eine konvergente Teilfolge. Denn der limsup ist ein Häufungspunkt, und dazu gibt es per Definition eine Teilfolge, die gegen ihn konvergiert.

Beispiel

Die Folge 0, 1/2, 1, 0, 1/4, 1/2, 3/4, 1, 0, 1/8, 2/8, …, 1, … läuft in immer feineren Schritten von 0 nach 1. Jede Zahl in [0, 1] wird immer wieder beliebig genau angenähert. Darum ist die Menge der Häufungspunkte das ganze Intervall [0, 1], mit liminf = 0 und limsup = 1. Eine Folge kann also unendlich viele Häufungspunkte haben.

3.6Das Cauchy-Kriterium

Satz 3.13 · Cauchy-Kriterium

(xn) konvergiert genau dann, wenn es zu jedem ε > 0 ein N gibt mit |xn − xm| < ε für alle m, n > N.

Auf Deutsch: Die Folgenglieder kommen sich gegenseitig beliebig nah. Das Besondere: In der Bedingung kommt der Grenzwert gar nicht vor. Du kannst also beweisen, dass eine Folge konvergiert, ohne zu wissen, wogegen.

Beispiel

xn = 1/n: Für m, n > N gilt |1/n − 1/m| ≤ max(1/n, 1/m) < 1/N, und das ist kleiner als ε, sobald N ≥ 1/ε. Also ist die Folge Cauchy.

Merke: so hängt alles zusammen

Der Beweis von „Cauchy ⇒ konvergent“ benutzt Bolzano-Weierstraß, und der benutzt die Vollständigkeit von ℝ. In ℚ geht das schief: Die Dezimalnäherungen 1, 1.4, 1.41, 1.414, … von √2 sind eine Cauchy-Folge rationaler Zahlen, aber ihr Grenzwert ist nicht rational. Das Loch in ℚ aus Kapitel 2 taucht hier wieder auf.

Übung

Für beschränkte Folgen sind diese drei Aussagen gleichwertig: (1) die Folge konvergiert, (2) sie hat genau einen Häufungspunkt, (3) limsup = liminf. Das folgt direkt aus Satz 3.12.

Selbst testen
Zeige mit ε-N: (2n + 1)/n → 2.

|(2n+1)/n − 2| = 1/n. Zu ε > 0 wähle N > 1/ε, dann ist der Abstand für n ≥ N kleiner als ε.

Bestimme limsup und liminf von xₙ = (−1)ⁿ + 1/n.

Gerade n: 1 + 1/n → 1. Ungerade n: −1 + 1/n → −1. Also limsup = 1, liminf = −1, die Folge konvergiert nicht.

Wahr oder falsch: Jede monotone Folge konvergiert.

Falsch. Es braucht zusätzlich Beschränktheit. Gegenbeispiel: xn = n ist monoton wachsend und geht gegen +∞.

Gegen was konvergiert (n² − 4n) / (2n² + 7)?

Durch n² teilen: (1 − 4/n)/(2 + 7/n²) → 1/2.
