# Easy Analysis

Statische Lernseite mit eigenen Erklärungen und Beispielen zu den Grundlagen der Analysis.

## Veröffentlichen mit Vercel

1. Auf vercel.com „Add New → Project“ wählen und dieses Repo importieren.
2. Framework Preset: **Other**, kein Build Command, Output Directory leer lassen.
3. Deploy. Die Seite ist `index.html`.
